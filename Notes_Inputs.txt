Feature:4 : Pending / Future Idea
Move API credentials to .env file (Local & Cloud VM)

• Concept: Decouple Kite API credentials (`api_key`, `api_secret`) from `program_config.json` into a `.env` file for enhanced security across local development and cloud deployments.
• Precedence Order:
    1. System / Shell Environment (`os.environ`)
    2. Root `.env` file (`paths.PROJECT_ROOT / .env`)
    3. Fallback to `program_config.json` (legacy compatibility)
• Architecture & Files to Touch:
    1. `common/session.py`: Lightweight zero-dependency `.env` loader (`load_env_file()`) + canonical `get_kite_credentials()`.
    2. `input/program_config.json`: Strip `api_key` and `api_secret` fields so it strictly manages strategy configs.
    3. `.env.example`: Template with placeholder keys committed to git.
    4. `.env`: Real credentials stored locally (protected by `.gitignore`).
    5. `Trade_Option/app_option_Trade.py` & `Trade_Stock/app_Stock_Trade.py`: Import `get_kite_credentials()` and update `/api/save-credentials` to write to `.env`.
    6. `Kite_Access_Token_gen.py`: Read credentials via `get_kite_credentials()`.
• Oracle Cloud VM Setup:
    1. One-time `.env` creation on VM at `$APP_DIR/.env`.
    2. Systemd services (`trading-options.service`, `trading-stock.service`, `trading-export.service`): add `EnvironmentFile=$APP_DIR/.env`.
    3. `sync_to_oracle_cloud.py`: Ensure `.env` is skipped from tar package to preserve VM credentials.
